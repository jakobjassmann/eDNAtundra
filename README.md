## Content

This repository contains the scripts needed to regenerate the figures and analyses presented in Assmann et al. - Combined eDNA and spectral variability facilitate rapid assessment of plant diversity in Arctic tundra landscapes.

*Note: Addtional data (drone and satellite imagery, sequences, coordinates etc.) are required. These are available via Zenodo and through external resources. Some intermediate  data products and all final tables and figures are included in this repository.  See details below.

## 1. Folder structure

This code repostiory has the following folder stucture:

```
data/                                   
  |- analysis/                          - Intermediate data products generated by the analysis.
  |- botanical_obs/                     - Placeholder folder for the botanical observations: vascular plant and bryophyte presence (on Zenodo).
  |- drone_data/                        - Placeholder folder(s) for the multispectral and RGB drone RGB imagery (on Zenodo).
  |- external/
        |- reference_libraries/         - Placeholder folder for the external reference libraries.
        |- species_list/                - Placeholder folder for the external species lists (see below).
  |- geometries/                        - Placeholder folder for the geometries (on Zenodo).
  |- sentinel/                          - Placeholder folder for the satellite imagery used in Figure 1 (see below). 
  |- sequences/                         - Placeholder folder for the DNA sequences (on Zenodo).
figures/                                - Figure outputs generated by the scripts in /scripts/figures .                                   
scripts/
  |- 1_data_prep                        - Scripts to prepare the data for the analysis.
  |- 2_analysis/                        - Scripts to carry out the analysis presented in the manuscript.
  |- 3_figures/                         - Scripts to generate the figures presented in the manuscript.
  |- 4_helper_scripts/                  - Helper scripts generating data products used for fieldwork or external communications.
  |- 5_archived_scripts/                - Legacy scripts not needed for the analysis.
tables/                                 - Tables presented in the supplementary materials.
```

## 2. Required data

To following data are not included in this code repository, but are required to regenerate the analysis.   

### Data collected by the authors

- Botanical observations (species presence / absence)
- RGB and multispectral drone imagery. 
- Amplicon sequences - eDNA metabarcoding and reference samples.
- Plot and site geometries.

These data can be found on Zenodo:

Assmann et al. 2024. Dataset for "Combined eDNA and spectral variability facilitate rapid assessment of plant diversity in Arctic tundra landscapes". Zenodo. [https://PLACEHOLDER](https://doi.org/PLACEHOLDER)

The data is currently under embargo and will be made openly available after peer-review. A copy of the data has been made available to the reviewers via a dedicated link for peer-review. 

To integrate these data into the repository, copy the Zenodo archive into the `/data` folder of a local copy of this repository. 

### External ITS and trnL reference databases

To curate the custom reference database used for the analyses, the user will need to download the following reference databases:
- DS-BITSR as tsv available at: https://doi.org/10.5883/DS-BITSR
- DS-VASCAN as tsv available at: https://doi.org/10.5883/DS-VASCAN
- DS-ZACKPLAN as tsv available at: https://doi.org/10.5883/DS-ZACKPLAN
- Willerslev et al. 2014 "references.arctic-gh.fasta" at: https://datadryad.org/dataset/doi:10.5061/dryad.ph8s5

The tsv / fasta files will need to be placed in the respective sub-folders of `data/external/reference_libraries/`.

### Satellite data used in Figure 1

The map in Figure 1 is derived from Copernicus Sentinel-2 satellite imagery. To recreate the map, the user needs to download the Sentinel-2 data product for tile 13WDS with ID "S2B_MSIL2A_20230808T190919_N0510_R056_T13WDS_20241022T234233". The data is available through the Copernicus archives which can be accessed via https://browser.dataspace.copernicus.eu. The product needs to be cropped to x [470922.11, 522119.90] and y [7654069.71, 7687033.23] (EPSG:32613 - WGS 84 / UTM zone 13N) and saved in `data/sentinel` using the filename specified in `scripts/3_figures/fig_1_map.r`. 

### Saarela et al. 2020 species list

If the user wishes to regenerate the subset of the species lists from Saarela et al. 2020 used for the field data sheets (this is not required for the analysis), they need to download `phytokeys-141-001-s003.xlsx` provided in the supplementary materials by Saarela et al. 2020 and paste it into the `data/species_list/` folder.

Saarela, J.M., Sokoloff, P.C., Gillespie, L.J., Bull, R.D., Bennett, B.A., Ponomarenko, S., 2020. Vascular plants of Vic, but used during data collectiontoria Island (Northwest Territories and Nunavut, Canada): a specimen-based study of an Arctic flora. PhytoKeys 141, 1–330. https://doi.org/10.3897/phytokeys.141.48810

## 3. Analysis workflow
To reproduce the analysis, tables and figures, we recommend running the scripts in the sequence listed below.

**Environment preparation**
- Download data from Zenodo and external resources, integrate it into folder structure as described above.
- Restore the local R environment from the lock file using renv::restore().

**Data preparation**
- Run all scripts in `scripts/1_data_prep/` in the sequence indicated by the filenames.

**Analyses**
- Run scripts in `scripts/2_analysis/`  in the sequence indicated by the filenames.

**Figures / Tables**<br><br>
All figures in the main manuscript are generated using the scripts in `scripts/4_figures/`. Figures and tables presented in the supplementary materials are generated by the analysis scripts (above) or by the scripts for the figures in the main manuscript.
