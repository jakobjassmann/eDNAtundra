## Content

This repository contains the scripts needed to regenerate the figures and analyses presented in Assmann et al. - Combined eDNA and spectral variability facilitate rapid assessment of plant diversity in Arctic tundra landscapes.

*Note: Addtional data (drone and satellite imagery, sequences, coordinates etc.) are required. These are available via Zenodo and through external resources. Some intermediate  data products and all final tables and figures are included in this repository.  See details below.

**External ITS and trnL reference databases** 

To curate the custom reference database using the scripts provided, the user will need to download the following reference databases:
- DS-BITSR as tsv available at: https://doi.org/10.5883/DS-BITSR
- DS-VASCAN as tsv available at: https://doi.org/10.5883/DS-VASCAN
- DS-ZACKPLAN as tsv available at: https://doi.org/10.5883/DS-ZACKPLAN
- Willerslev et al. 2014 "references.arctic-gh.fasta" at: https://datadryad.org/dataset/doi:10.5061/dryad.ph8s5

The tsv / fasta files will need to be placed in the respective subfolders of `data/external/reference_libraries/` (see placeholders).

## 3. Analysis workflow
We recommend to run the scripts in the sequence as listed below.

**Environment and data preparation**
- Download data from Zenodo and external resources, integrated in folder structure as described above.
- Prepare R environment using renv::restore().
- Run scripts in `scripts/1_data_prep/` in sequence indicated by filenames.

**Analyses**
- Run scripts in `scripts/2_analysis/` in sequence indicated by filenames.
